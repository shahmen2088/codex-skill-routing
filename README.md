# Codex Skill Routing

Набор из четырёх навыков для выбора, сочетания и проверки Agent Skills в Codex и OpenCode.

## Зачем нужен репозиторий

Нативный механизм уже умеет подбирать один навык по `name` и `description`. Дополнительный маршрутизатор нужен не всегда, а в трёх случаях:

- запрос неоднозначен и подходит нескольким навыкам;
- результат требует нескольких предметных областей;
- навыки пересекаются, конфликтуют или должны выполняться в определённом порядке.

Маршрутизация использует progressive disclosure: сначала читаются метаданные, затем только выбранные `SKILL.md`, а дополнительные references — по необходимости.

## Навыки

| Навык | Когда применять | Результат |
|---|---|---|
| `skill-router` | Неясно, какой навык подходит, или нужны несколько областей | Один основной навык, до двух вспомогательных, уверенность и причины выбора |
| `workflow-router` | Задачу нужно разбить или координировать | Single, sequential, parallel, supervisor или handoff topology |
| `skill-conflict-resolver` | Выбранные навыки пересекаются или дают несовместимые указания | Разрешённый порядок, исключённые шаги и сохранённые ограничения |
| `routing-evaluator` | Нужно проверить качество активации и маршрутов | Набор direct/indirect/follow-up/negative/boundary тестов и отчёт |

## Рекомендуемый порядок

```text
Запрос → нативный выбор по metadata
       → точное совпадение: один skill
       → неоднозначность: skill-router
       → составная задача: workflow-router
       → конфликт: skill-conflict-resolver
       → исполнение → проверка
```

Чтобы маршрутизатор применялся в нужный момент, добавьте короткое правило из [`templates/AGENTS-routing.md`](templates/AGENTS-routing.md) в проектный `AGENTS.md`. Оно не загружает все навыки и не заставляет вызывать router для простых запросов.

## Установка

```powershell
pwsh .\install.ps1 -Target codex
pwsh .\install.ps1 -Target opencode
```

По умолчанию:

- Codex: `%USERPROFILE%\.codex\skills`
- OpenCode: `%USERPROFILE%\.config\opencode\skills`

Скрипт останавливается, если целевой навык уже существует. Для обновления сначала сравните локальные изменения и удалите или переименуйте старую копию вручную.

## Реестр навыков

Построить компактный JSON-индекс из одной или нескольких библиотек:

```powershell
pwsh .\scripts\build-registry.ps1 `
  -Roots "$env:USERPROFILE\.codex\skills", ".\skills" `
  -OutputPath ".\skill-registry.json"
```

В индекс попадают только имя, описание, путь и источник. Тела `SKILL.md` не копируются.

## Проверка

```powershell
pwsh .\scripts\validate.ps1
```

Сценарии активации находятся в [`tests/activation-cases.md`](tests/activation-cases.md), контракт результата — в [`references/routing-contract.md`](references/routing-contract.md).
