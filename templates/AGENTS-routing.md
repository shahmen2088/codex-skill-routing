# Skill routing bootstrap

- Перед существенной работой сравнивай запрос только с `name` и `description` доступных skills.
- Если есть одно точное совпадение, загрузи этот skill напрямую.
- Если запрос неоднозначен, затрагивает несколько предметных областей или требует упорядочить skills, примени `skill-router`.
- Выбирай один основной skill и не более двух вспомогательных, если задача явно не требует большего.
- Не загружай тела всего каталога. Отсутствие подходящего skill допустимо: продолжай обычную работу и не выдумывай соответствие.
- Явно указанный пользователем skill сохраняет приоритет; дополнительные skills не расширяют разрешения задачи.
